# 1\. 引言

## **1\.1\. 文档目的**

本软件需求规格说明书（SRS）旨在为“日本教育机构综合办公自动化系统”的研发、验收与运维提供完整、准确、可追溯的需求定义。具体预期用途如下：



\- **需求基线确立**：作为项目开发全流程的需求基准，明确系统功能边界、非功能约束与数据规范，指导后续概要设计、详细设计、编码实现与测试用例编写。

\- **技术选型与架构决策依据**：为系统架构设计、接口体系（IF\-API / IS\-API / CS\-API / EX\-API）划分、模块拆分及存储方案选型提供业务层面的需求支撑。

\- **验收与变更管理**：作为最终系统验收的评判标准，同时为需求变更提供影响分析与版本管控的原始参照。



本文件的目标读者及其使用方式如下：



|目标读者|使用方式|
|---|---|
|项目管理层（项目经理、产品负责人）|理解项目整体范围与业务价值，据此制定开发计划、资源分配与里程碑节点；在评审中确认需求完整性，把控项目风险。|
|系统架构师与开发团队|根据各模块功能需求、接口定义与数据结构描述，进行模块化设计与编码实现；参照非功能性需求（性能、安全、可用性等）进行技术选型与性能调优。|
|测试与质量保证团队|依据需求条目编写测试用例，验证系统功能实现是否满足规格；在回归测试中追踪变更影响范围。|
|日本教育机构的业务干系人（校方管理者、教务人员、财务人员等）|了解系统能力与操作流程，提前规划业务迁移与用户培训方案；在评审中对需求细节进行确认，确保系统贴合实际业务场景。|
|运维与技术支持团队|熟悉系统部署架构、数据备份策略及外部接口依赖，为上线后的日常运维、故障排查提供参考。|
|外部系统集成方（如支付网关、在线课堂平台等）|查阅外部服务接口（EX\-API）定义，明确对接协议、数据格式与安全约束，完成联调与集成测试。|



读者应结合本文档中的术语定义、模块用例及数据模型章节，按角色关注对应内容；开发与测试人员应以本文档为最终需求来源，任何歧义或疑点应通过正式需求变更流程反馈，而非自行推断。

## **1\.2\. 项目背景**

日本教育机构（包括大学、专门学校、语言学校等）在日常运营中普遍面临多业务系统割裂、数据孤岛严重、运维成本高昂等问题。具体表现为：



\- **报考流程繁琐**：考生报名、缴费、考试确认等环节依赖线下或半线下操作，效率低下且易出错；

\- **人事管理分散**：职员信息、考勤、薪酬、绩效等数据分别维护，缺乏统一视图，影响管理决策；

\- **教务与财务脱节**：课程安排、学籍管理、出勤统计等教务数据与学费收缴、预算管理等财务流程无法自动联动，增加人工核对成本；

\- **缺乏统一协同平台**：任务指派、进度追踪、成果评估等工作缺乏系统化支撑，跨部门协作依赖邮件或口头沟通；

\- **在线教学需求迫切**：混合式教学已成为常态，机构需要稳定的在线课堂平台来支撑课程资源分享、课题提交与在线考试。



本项目旨在构建一套面向日本各大教育机构的综合性办公自动化系统，整合上述核心业务场景，通过统一的账户体系与模块化的子系统架构，消除信息孤岛，提升运营效率，降低管理成本，为教育机构的数字化转型提供一站式解决方案。

## **1\.3\. 术语与定义**

本文档中使用的专有名词及其定义如下：



|分类|中文名称|英文名称及缩写|描述|
|---|---|---|---|
|API|系统前端接口|Internal Frontend API（IF\-API）|同一子系统内，仅限自己的前端调用；不暴露给任何其他子系统或外部。|
|API|系统互通接口|Inter\-Subsystem API（IS\-API）|调用方是其他子系统的后端服务；只在内部可信网络内互相调用。|
|API|内核服务接口|Core Service API（CS\-API）|被调用方是独立于子系统的系统内核服务；只在内部相互调用。|
|API|外部服务接口|External API（EX\-API）|调用方或被调用方是外部平台/服务，穿越系统边界，需经过外联网关。|
|UI|界面|Screen|指用户在应用中一次可完整感知、具有独立业务语义和导航节点的 UI 单元。用户通常通过导航（如路由、页面跳转、Tab 切换、返回等）进入或离开一个界面。在 Web/IOS/Android 中可能对应不同的实体。|
|DATA|伪数据库|Pseudo Database|指重点关注实体及其属性间关系的数据库结构设计。用于快速展示实体间关系。其结构可能违反数据库设计范式，并不能直接与实际数据表相对应。|
|DATA|伪存储池|Pseudo Storge|指重点关注存储文件集合及集合内文件种类的存储池结构设计。用于快速展示存储池内容。其结构并不能直接与实际存储文件树相对应。|
