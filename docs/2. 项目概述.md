# 2\. 项目概述

## **2\.1\. 产品目标**

本产品的核心业务价值与可衡量的成功指标如下：



|业务目标|说明|可衡量指标|
|---|---|---|
|业务一体化|将全局通用系统（COMMON）、在线报考系统（IAS）、人事管理系统（HRS）、财务管理系统（FMS）、任务管理系统（TMS）、教务管理系统（EDU）、事务管理系统（OMS）、总务管理系统（AMS）、在线课堂系统（LMS）、智能助理系统（AIA）共十大子系统整合至统一平台，消除数据孤岛|各子系统间数据自动同步率达 100%，无需人工二次录入|
|高效协作|通过任务管理模块在系统内部实现跨子系统的任务指派、追踪与成果评估|任务流转响应时间 ≤1s，任务状态更新延迟 ≤500ms|
|安全可靠的账户体系|提供统一的身份认证与权限管理，用户一次登录即可访问所有授权子系统|跨子系统登录成功率 ≥99\.9%，会话有效期内无重复认证请求|
|灵活部署能力|支持本地部署与云端部署两种模式，满足不同教育机构的合规与预算需求|单次部署上线周期 ≤3 个工作日，切换部署模式无数据丢失|
|高性能用户体验|在高并发场景下保持流畅的交互体验|并发用户数 ≥1000，平均响应时间 ≤1s，可用性 ≥99\.9%|
|教学场景全覆盖|支持从课程资源分享到在线考试的全链路教学闭环|在线课堂模块支持同时在线 ≥5000 用户，视频传输延迟 ≤500ms|





## **2\.2\. 产品范围**

本产品为“日本教育机构综合办公自动化系统”的首个正式发布版本，旨在为日本各类教育机构提供一体化的内部业务管理平台。本期交付功能严格限定于以下业务子系统与内核服务模块，并配套统一的身份认证与权限管理后台。  

所有子系统之间保持独立部署、最大限度解耦，仅通过标准化 API 进行交互。



### **包含的功能范畴**



本期交付覆盖以下内核服务模块与核心业务子系统。各模块的详细职责与功能说明见第 3\.3 节。



\- **内核服务**：账户服务、邮件服务、通知服务等系统系统内核服务。

\- **业务子系统**：在线报考系统（IAS）、人事管理系统（HRS）等业务独立子系统。



### **不包含的功能范畴**



本期交付明确**不包含**以下内容：



- 第三方支付渠道的原生集成（支付功能通过标准接口由合作方提供，本系统仅对接接口）

- 视频直播/点播的底层流媒体服务（由 CDN 或流媒体服务商提供，本系统仅集成）

- 移动端原生应用（iOS/Android）的开发与交付（本期仅交付 Web 客户端，架构预留移动端扩展能力）

- 与日本各教育机构现有遗留系统的深度定制对接（标准化 API 对外暴露，定制适配由二期规划）

## **2\.4\. 运行环境**



\- **浏览器**：现代浏览器（Chrome ≥ 90、Firefox ≥ 90、Safari ≥ 15、Edge ≥ 90），需启用 Cookie 与 JavaScript

\- **网络**：需连接至服务端，API 请求延迟 ≤ 2s，推荐带宽 ≥ 10Mbps

\- **服务端**：Nginx（静态资源分发 \+ 反向代理）、Go 后端（监听 127\.0\.0\.1:8080）、关系型数据库（独立部署）、对象存储（S3 兼容或 WebDAV）

\- **开发环境**：Visual Studio Code，Node\.js ≥ 20，Go ≥ 1\.21





## **2\.5\. 假设与依赖**



- 用户拥有可正常访问互联网/局域网的现代浏览器设备

- 数据库服务可用，支持基于日志的增量备份与异地灾备

- SMTP 邮件服务器可用，用于事务邮件发送

- S3 兼容或 WebDAV 兼容的对象存储服务可用

- 开发团队可访问代码仓库、接口管理平台、协作平台及文件共享服务

- TLS 证书就绪，生产环境启用 HTTPS

- 缓存服务可用（会话共享、缓存加速）
