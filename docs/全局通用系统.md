# 1\. 全局通用系统

本节集中定义**独立于业务场景的全局通用服务**，它们为各子系统提供共享的基础能力。下列各小节将对这些模块进行详细描述：



- **6\.1\.1 业务规则** – 账户生命周期规则、权限模型（RBAC \+ 可自定义策略）、通知触发条件、消息保留策略、存储安全规则等。

- **6\.1\.2 功能需求** – 以用例形式列出账户注册/登录/注销、通知管理、消息收发、邮件发送、文件上传/下载、后台管理等通用功能点。

- **6\.1\.3 数据需求** – 通用数据实体，如用户、角色、权限、通知、消息、邮件队列、文件元数据等。

- **6\.1\.4 接口需求** – 账户、通知、消息、邮件、存储、管理各模块 API 的完整规范（请求/响应、头信息、错误码）。

- **6\.1\.5 界面设计** – 通用登录页、通知中心、消息面板、文件选择器、后台管理控制台等关键界面原型与交互说明。
